# Tích Hợp Hệ Thống

Repository tổng hợp các bài tập và đề thi môn Tích Hợp Hệ Thống.

## Danh sách đề tài & bài tập:
- `De1_TichHop`: Đề 1 - Bài tập tích hợp hệ thống (XML, XSD, XSL, Java/Maven).
- `DeCongTy2_TichHop`: Đề Công Ty 2 - Quản lý công ty (XML, XSD, XSL, HTML).
- `DeNhaSach_TichHop`: Đề Nhà Sách - Quản lý nhà sách (XML, XSD, XSL, HTML).

## Cấu trúc thư mục:
```text
TichHop-HeThong/
├── De1_TichHop/
│   ├── pom.xml
│   └── src/
├── DeCongTy2_TichHop/
│   ├── pom.xml
│   └── src/
└── DeNhaSach_TichHop/
    ├── pom.xml
    └── src/
```
